# Flowba.io — nouvelle page d'accueil

Page d'accueil statique (un seul fichier `index.html`, sans dépendance) pour flowba.io, en français québécois.

## Structure
1. Bandeau offre du mois (diagnostic IA gratuit)
2. Hero : promesse + vidéo promo + 1 CTA principal
3. Problèmes (appels manqués, messages éparpillés, paperasse)
4. Pour qui : garages, entrepreneurs, courtiers immobiliers
5. Solutions (4 agents)
6. « On branche l'IA sur vos vrais outils »
7. Méthode en 3 étapes (diagnostic → pilote → expansion)
8. Forfaits (prix à compléter)
9. Financement possible (avec avertissement)
10. Témoignages (places pilotes, à remplacer par de vrais avis)
11. FAQ
12. Contact (téléphone, courriel, WhatsApp, formulaire)

## À compléter
- Les prix des forfaits (« Sur soumission » pour l'instant).
- Les liens Facebook / Instagram / TikTok du pied de page.
- Le formulaire ouvre un courriel prérempli ; le brancher sur Formspree, WordPress ou un CRM pour recevoir les demandes directement.
- Version anglaise (bouton EN).

## Aperçu local
Ouvrir `index.html` dans un navigateur.
